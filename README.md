# SOC-teory

Событие - это факт, а инцидент - это проблема.

Событие - это любая наблюдаемая операция или изменение состояния в системе. Это «сырые данные».

Инцидент - это событие (или совокупность событий), которое нарушает политики безопасности или указывает на реальную угрозу, требующую реакции.
________________

OSI 7 уровней

Модель OSI (Open Systems Interconnection) — это эталонная модель, которая описывает, как данные передаются по сети. Она делит этот процесс на 7 уровней.

1) ФИЗИЧЕСКИЙ L1

    Что делает: Передача битов (0 и 1) по кабелю, радиоволнам или оптоволокну.

    Единица: Бит.
   
    Примеры: Кабели (RJ-45, оптика), хабы, розетки.

    Безопасность: Физический доступ к серверной, прослушка кабеля (tap), глушение Wi-Fi (jamming).

2) КАНАЛЬНЫЙ L2

     Что делает: Доставка кадров внутри одной локальной сети (LAN). Адресация по MAC-адресам.

     Единица: Кадр (Frame).

     Адресация: MAC-адрес (физический адрес сетевой карты).

     Протоколы: Ethernet, ARP, VLAN (802.1Q).

        Ethernet (Эзернет)
        Это самый базовый стандарт проводной локальной сети. Это семейство технологий для проводных локальных сетей (LAN).
        Что делает: Определяет, как данные упаковываются в «кадры» (frames) и передаются по кабелю.
        Главная фишка: Использует MAC-адреса (физические адреса сетевых карт

        ARP (Address Resolution Protocol)
        Это «переводчик» между 3-м и 2-м уровнем.
        Проблема: Компьютер знает IP-адрес цели (например, шлюза 192.168.1.1), но чтобы отправить кадр по Ethernet, ему нужен MAC-адрес этого шлюза. IP тут не работает.
        Решение: Компьютер кричит во всю сеть: «Эй, у кого IP 192.168.1.1? Назовите свой MAC!». Владелец IP отвечает: «Это я, мой MAC такой-то».

        Virtual LAN — виртуальная локальная сеть.
        Зачем нужно: Чтобы разделить один физический свитч на несколько логических сетей. Например, бухгалтерия не должна видеть трафик гостей Wi-Fi, хотя все подключены к одному оборудованию.
        Как работает (802.1Q): В обычный Ethernet-кадр вставляется специальный тег (tag) с номером VLAN (ID от 1 до 4094). Свитч читает этот тег и решает, куда пустить пакет.

     Безопасность: ARP-spoofing, MAC-flooding, атаки на коммутаторы. В логах это видно редко, нужно смотреть на уровне свичей или через зеркалирование портов.

3) Сетевой (Network) Критичен для SOC
   
      Что делает: Маршрутизация пакетов между разными сетями (например, из твоего офиса в интернет). Логическая адресация
   
      Единица: Пакет (Packet).
   
      Адресация: IP-адрес (v4/v6).
   
      Протоколы: IP, ICMP (ping), IPSec.
   
        IP (Internet Protocol)
        Фундамент всего интернета и большинства локальных сетей.
        Что делает: Адресация и маршрутизация. Каждый пакет имеет заголовок с Source IP и Destination IP

        ICMP (Internet Control Message Protocol)
        Протокол диагностики и управления. Тот самый «ping».
        Что делает: Сообщает об ошибках доставки, проверяет доступность хостов (Echo Request/Reply), сообщает о превышении TTL (traceroute).

         IPSec (Internet Protocol Security)
         Не отдельный протокол, а набор протоколов для защиты IP-трафика на сетевом уровне.
         Что делает: Шифрует и/или аутентифицирует каждый IP-пакет. Работает прозрачно для приложений (в отличие от TLS на 6-7 уровне).
   
          Два режима:
          Transport Mode: Шифруется только payload (данные доставки) пакета. Используется для host-to-host (например, сервер-сервер).
   
          Tunnel Mode: Шифруется весь оригинальный пакет, включая его IP-заголовки. Используется для VPN (site-to-site).

      Оборудование: Роутеры, L3-коммутаторы.
   
      Безопасность: Сканирование портов (Nmap), DDoS (SYN flood), подмена IP (spoofing), маршрутизация.
      В Elastic: Поля source.ip, destination.ip, network.transport.

4)   Транспортный (Transport) 🔥 Критичен для SOC
   
     Что делает: Доставка данных от процесса к процессу. Гарантирует надежность (или скорость).
   Единица: Сегмент (Segment) / Дейтаграмма.
 
      Адресация: Порты (Port numbers).
  
      Протоколы: TCP (надежный, рукопожатие), UDP (быстрый, без гарантий).

         TCP (Transmission Control Protocol)
         Ключевая фишка: Рукопожатие (SYN → SYN-ACK → ACK).
         ARP (Address Resolution Protocol)
         Это «переводчик» между 3-м и 2-м уровнем.

         UDP (User Datagram Protocol)
         Ключевая фишка: "Отправил и забыл". Нет подтверждения доставки.
     
       Безопасность:  TCP Handshake (SYN-SYN/ACK-ACK) — база для обнаружения сканов.
     
         Клиент отправляет список поддерживаемых версий TLS (1.2, 1.3), наборов шифров (cipher suites) и случайное число.

         Сервер выбирает лучшую версию и шифр из предложенных клиентом. Затем он отправляет свой SSL-сертификат. В сертификате зашифрован публичный ключ сервера и информация о том, кому он выдан (например, google.com).
         
        В Elastic: Поля source.port, destination.port, network.transport (tcp/udp).
        TCP: Всегда смотрите на флаги (tcp.flags).
        UDP: Смотрите на размер пакетов (udp.length) и частоту.

5)  Сеансовый (Session)
   
    Что делает: Управление сеансом связи (установка, поддержка, разрыв) аутентификация и управление состоянием соединения. Синхронизация диалога.
    Протоколы: NetBIOS, RPC, PPTP.

             RPC (Remote Procedure Call) — «Нервная система» Windows
             Это самый важный протокол для защиты AD. Он позволяет одной программе вызывать код на другой машине так, будто он выполняется локально.

             NetBIOS — «Эхо прошлого» и вектор атак
             Старый протокол именования и сеансов (порты 137/UDP, 138/UDP, 139/TCP).

              PPTP / L2TP — Туннелирование и обход
              Протоколы создания виртуальных частных сетей. Они инкапсулируют трафик внутри другого соединения.

    Безопасность: Hijacking сессий (перехват управления соединением). Часто этот уровень объединяют с транспортным или прикладным в современных реализациях.

6) Представления (Presentation)

      Что делает: Шифрование, сжатие, кодирование данных. Протоколы: SSL/TLS, JPEG, ASCII.
   
      Для ИБ: Weak crypto, Downgrade attacks, Malware obfuscation, Data exfiltration via encoding.
   
      Логи: Proxy logs, TLS metadata (JA3/JA4), DLP.

       Proxy расшифровывает трафик, проверяет его и шифрует заново.
       DLP работает на уровне представления, потому что анализирует содержимое данных после дешифровки/декодирования.

7) Прикладной (Application)

      Что делает: Взаимодействие с пользователем, приложения. Протоколы: HTTP, DNS, SMTP, FTP, SMB.
           
       HTTP/HTTPS: «Публичное лицо и главный вход»
        Бизнес-роль: Доставка контента, работа веб-приложений, API, облачные сервисы. Это основной интерфейс взаимодействия с внешним миром.

       DNS: «Телефонная книга и скрытый туннель»
        Бизнес-роль: Преобразование понятных человеку доменных имен в IP-адреса. Без DNS интернет не работает.

        FTP: «Устаревший склад и дыра в безопасности»
        Бизнес-роль: Legacy-передача файлов, обмен данными со старыми партнерами/системами.
   
       SMB: «Внутренняя кровеносная система и магистраль латерального движения»
        Бизнес-роль: Совместный доступ к файлам, принтерам, IPC внутри Windows-сети. Основа работы Active Directory.
   
   Для ИБ: SQLi, XSS, Phishing, Brute-force, Command Injection, Malware download.

      Логи: Web server logs, WAF, Email gateway, EDR, Application logs.

       Web Server Logs (Apache/Nginx/IIS)
       Что видят: «Сырые» факты доступа. Кто пришел, куда постучался, какой получил ответ.

       WAF (Web Application Firewall) — это межсетевой экран для (HTTP/HTTPS). В отличие от обычного файрвола, который смотрит на IP и порты, WAF «читает» содержимое веб-запросов и понимает логику приложений.

        Application Logs показывают намерения и решения самого приложения.

       Email gateway стоит между интернетом и вашей корпоративной почтовой системой.

       EDR (Endpoint Detection and Response) — это «черный ящик» и «видеорегистратор» для каждого компьютера в сети. Он записывает всё, что происходит: запуск процессов, обращения к реестру, сетевые соединения, модификацию файлов.
